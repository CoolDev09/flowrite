# Offline US English spelling dictionary

`en_US.aff`, `en_US.dic`, and `README_en_US.txt` were obtained from the official
LibreOffice dictionaries repository on 10 October 2026:
https://github.com/LibreOffice/dictionaries/tree/master/en

The dictionary identifies itself as SCOWL/Hunspell version **2020.12.07**.
`README_en_US.txt` contains the complete upstream copyright, sources, credits,
and license terms. Keep it with the dictionary when redistributing.

flowrite embeds the dictionary and checks words locally using `spellbook`.
It does not send writing to a web service.
